# Header Component Specification

## Purpose
The Header acts as the persistent top navigation and status hub across the Camnex application.

## Features
- **Emergency / Security Notice Ribbon**: Displays operational network status (100% Uptime), compliance certifications, and toll-free surveillance hotline.
- **Brand Identity**: Stylized Camnex PRO logo with camera shield iconography.
- **Section Navigation**: Anchored links to Products, Turnkey Kits, Live Demo Grid, AI Features, and FAQ.
- **Interactive Tools**: Trigger for the System Cost Calculator modal.
- **Quote / Cart Counter**: Badge indicator displaying the number of hardware units in the active proposal bill.
- **Responsive Drawer**: Collapsible mobile menu for small viewport navigation.
