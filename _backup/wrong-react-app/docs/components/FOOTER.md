# Footer Component Specification

## Purpose
Provides global compliance badges, legal disclosures, technical support channels, and structural navigation links.

## Elements
- **Compliance Ribbon**: NDAA Section 889 compliance, ONVIF Profile S/G/T, FCC/CE certification, and IK10 vandal resistance.
- **Hardware Solutions Links**: Direct links to Dome, Bullet, PTZ, Solar, and NVR categories.
- **Turnkey Kits**: Direct access to kits and system calculators.
- **Contact & Hotline**: Phone numbers, emails, and address for Camnex Innovations Technology Labs.
