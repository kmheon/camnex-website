# Package Card Specification

## Purpose
Displays turnkey pre-configured surveillance packages with all necessary components for immediate deployment.

## Features
- **Tier Title & Target Demographic**: Clear delineation between Home Shield Essential, Business Guard Pro, and Enterprise Fortress Suite.
- **Inclusions Breakdown**:
  - Quantity and model breakdown of included cameras.
  - Pre-installed surveillance hard drive capacity & retention days.
  - Included smart NVR hub with PoE ports.
- **Feature Checklist**: Verified inclusions like zero subscription fees, free Camnex View mobile app, and push notifications.
- **Selection & Customization**: Action button to order the turnkey kit or launch the system calculator to customize storage or camera mix.
