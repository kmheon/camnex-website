# Hero Component Specification

## Purpose
The Hero section communicates Camnex's primary value proposition: enterprise-grade 4K intelligent surveillance with zero mandatory subscriptions.

## Features
- **Primary Display Typography**: High-contrast headline emphasizing optical clarity and local control.
- **Value Checkmarks**: Highlights 0 cloud fees, ColorNight™ 200ft range, edge neural filtering, and ONVIF compliance.
- **CTA Actions**: Instant buttons to view pre-packaged kits, launch the live feed simulation, and open the custom system planner.
- **Interactive HUD Preview**: A simulated NVR security console featuring live 4K feed, neural bounding boxes, target lock metadata, and storage counters.
