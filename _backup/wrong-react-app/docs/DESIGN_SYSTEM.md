# Camnex Design System

## Typography
- **Headings**: Space Grotesk (`font-heading`) paired with Plus Jakarta Sans for high-tech, precision engineering aesthetics.
- **Body**: Plus Jakarta Sans for high readability across dense technical specifications and data tables.
- **Monospace**: Clean font-mono for IP channels, FPS counters, bitrates, SKUs, and pricing.

## Palette
- **Background**: Deep Slate (`slate-950` / `#020617`), slate card containers (`slate-900` / `#0f172a`), subtle dividers (`slate-800`).
- **Primary Accent**: Electric Tech Blue (`blue-600` / `#2563eb`), hover state `blue-500`.
- **Status Accents**:
  - Emerald Green (`emerald-400` / `emerald-500`): Live feeds, online status, 0 monthly fees.
  - Signal Amber (`amber-400`): Customer star ratings, caution alerts.
  - Deterrence Rose (`rose-500` / `rose-600`): Recording tags, active sirens, perimeter tripwires.
  - Cyan (`cyan-400`): ColorNight™ Infrared vision, PTZ indicators.
