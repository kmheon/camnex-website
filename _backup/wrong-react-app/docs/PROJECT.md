# Camnex Website Architecture & Overview

## Project Mission
Camnex designs, manufactures, and deploys high-reliability CCTV surveillance systems and AI-powered edge analytics for residential estates, commercial facilities, and industrial warehouses.

## Core Pillars
1. **No Subscription Lock-in**: All cameras stream and record to local NVR or MicroSD storage with zero monthly fees.
2. **Edge Neural Detection**: Eliminates 99% of false alarms by classifying humans and vehicles directly on camera silicon.
3. **Turnkey Deployment**: Pre-configured packages with cameras, NVR, PoE cabling, and plug-and-play mobile pairing.
4. **Camnex View Ecosystem**: Native cross-platform monitoring application supporting live streaming, PTZ, and multi-channel synchronization.
