# CamneX Footer Component

Professional, clean, and corporate footer section designed for the CamneX homepage and website ecosystem.

## Features
* **5-Column Desktop Layout**: Structured cleanly into Company Info, Quick Links, Products, Customer Support, and Newsletter subscription.
* **Responsive Architecture**: Gracefully adapts from 5 columns on desktop to 2 columns on tablet and a single column on mobile devices.
* **Interactive Elements**: Includes smooth underline transitions on link hovers, styled social media buttons, and a smooth-scroll "Back To Top" utility button.
* **Design System Integration**: Built using the official CamneX dark theme variables (`#0F172A` / `#111827`), primary orange accents (`#F15A24`), and typography specs.
* **Accessibility**: Fully semantic HTML5 `<footer>` structure with explicit ARIA attributes and keyboard-accessible focus states.
