# Overview

The Package Card is a premium commerce component designed to promote complete security solution bundles rather than individual products.

It highlights the overall value of a package by presenting the included equipment, intended use, warranty, pricing, and key selling points in a clean, modern layout.

This component is one of the primary sales components of the CamneX website.

---

# Purpose

Help customers quickly understand what is included in a complete solution package and encourage them to explore or purchase the bundle.

Unlike the Product Card, the Package Card sells a complete solution rather than a single product.
