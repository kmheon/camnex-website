# Overview

The Property Solutions section is the first customer discovery section displayed on the homepage after the Hero.

Instead of asking visitors to browse products immediately, this section guides them to the most suitable security solution based on where they need protection.

This improves navigation, reduces decision fatigue, and provides a solution-first shopping experience.

---

# Purpose

Help customers quickly identify the most appropriate security solution for their property.

This feature acts as an entry point into the commerce experience by directing visitors toward relevant categories, packages, and products.

# Notes

The Property Solutions section is designed to guide customers toward the correct security solution before they begin browsing products.

Unlike Category Cards, which organize products, Property Cards organize the customer journey based on the visitor's environment and use case.

This feature should always remain simple, visual, and easy to understand.
